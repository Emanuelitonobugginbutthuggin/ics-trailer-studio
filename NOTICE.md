# Third-party software

ICS Trailer Studio is built on these open-source projects. All are free to use.

| Project | Used for | Licence |
|---|---|---|
| [three.js](https://github.com/mrdoob/three.js) 0.187 | 3D scene, camera, maths | MIT |
| [Spark](https://github.com/sparkjsdev/spark) 2.4.0 (World Labs) | Gaussian splat loading, rendering, sorting, edits | MIT |
| [Mediabunny](https://github.com/Vanilagy/mediabunny) 1.65.2 | MP4 container writing, reading video clips frame by frame | MPL-2.0 |
| [web-audio-beat-detector](https://github.com/chrisguttandin/web-audio-beat-detector) 8.2.39 | Tempo and first-beat detection | MIT |
| [Vite](https://github.com/vitejs/vite), [TypeScript](https://github.com/microsoft/TypeScript), [Vitest](https://github.com/vitest-dev/vitest) | Build and tests (not shipped in the app) | MIT / Apache-2.0 |

## Adapted code

`src/export/encoder.ts` and `src/export/h264Levels.ts` follow the video export
of [SuperSplat](https://github.com/playcanvas/supersplat) (`src/render.ts`,
`src/video-config.ts`), Copyright (c) 2011-2026 PlayCanvas Ltd., MIT licence:
the sort-wait-render-encode loop, the chained muxer writes used for
backpressure, recovery when the browser reclaims the codec, the Web Lock held
during a render, and the H.264 level table.

## Sample data

"Public sample" downloads `hornedlizard.spz` at run time from the
[nianticlabs/spz](https://github.com/nianticlabs/spz) repository (MIT). It is
not stored in this repository. `public/samples/demo-room.ply` is synthetic and
generated by `scripts/make-demo-room.mjs`.
